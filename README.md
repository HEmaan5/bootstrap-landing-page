# SipSmart - Responsive Landing Page

A responsive product landing page for a fictional smart mug, built with HTML5, CSS3 and Bootstrap 5.

## Features
- Responsive navbar (collapses on mobile)
- Hero section with call-to-action buttons
- Feature and pricing cards using the Bootstrap grid
- Multi-column footer

## How to run
Download `index.html` and open it in a browser (internet needed for the Bootstrap CDN).
